# Windows 版 ACAS

Windows 上で動作する WPF デスクトップアプリです。Web ビューを使用せず、固定長の業務データと帳票をローカルの SQLite に保持します。会社・会計期間の設定、勘定科目、仕訳の入力・照合・転記・締め、試算表、保管元帳、決算書、帳票の一覧・閲覧・保存・印刷を提供します。

## 開発時の実行

Windows で .NET 8 SDK を使用し、このディレクトリから実行します。

```powershell
dotnet build Acas.sln -c Release
dotnet test Acas.sln -c Release --no-build
dotnet run --project Acas.App -c Release --no-build
```

保存先はユーザーごとのローカルアプリケーションデータ内の `ACAS\acas.db` です。検証で通常の業務データと分離する場合は `-- --database <検証用データベースのパス>` を指定します。共有パス、ネットワークドライブ、リンクを経由するパスは使用できません。

業務画面の追加方法は [Windows 版 ACAS の開発手順](docs/DEVELOPING.md) を参照してください。

## 既知事項

- 旧環境の運用区分と印刷先は設定データとして保持します。Windows 版の保存先はローカル SQLite に固定され、実際の印刷先は Windows の印刷ダイアログで指定します。
- 総勘定元帳の期間締め（旧 GL080）は、レガシー実測に合わせて、現期間の仕訳を削除または保管し、バッチを保管済みにしてから圧縮直前で中断します。レガシーでは仕訳レコードが98バイト、圧縮用レコードが96バイトのため、GL112／GL113 が表示されます。途中の更新は残り、会計期間・四半期・元帳残高は変わりません。実行前に検証用データまたはバックアップで確認してください。

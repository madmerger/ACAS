# 簡易記帳・元帳連携の同一性検証

Windows の `windows/` で、添付の証跡アーカイブを指定して実行します。レガシーの端末画面は描画せず、新アプリと同じ画面モデルをメニュー、フォーム、確認の順に操作します。データベースはケースごとにメモリー上で初期化します。

```powershell
$env:DOTNET_ROOT = 'C:\dotnet'
dotnet run --project Acas.Verify.Irs -c Release -- "$HOME\ACAS_同一性確認テスト_証跡.zip" "$HOME\acas-irs-verify.json"
```

- 画面は、最終証跡の業務操作を識別する文言と、対応する画面モデルの型・題名を比較します。端末上の座標、残像、全中間画面、WPF の見た目は比較しません。
- 証跡で採取された論理レコードの差分をキー単位・バイト単位で比較します。採取対象にできなかった転記ファイル（`IRS-400`）と未決済明細（`INT-405`）は「論理レコード未採取」として出力します。
- 帳票はレガシー比較用本文を比較し、表示用の日本語本文とは分けます。改行コードと行末の空白は判定に含めません。
- 証跡台帳で「未実施」の場合のみ対象外です。ほかの不一致があれば終了コードは 1 です。
- 設定シナリオの再生では、端末の文字列上書きの挙動と、証跡の付加価値税率欄に反映されなかった入力を考慮し、実効値を型付きフォームに渡します。
